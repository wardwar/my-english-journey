# My English Journey

Roadmap belajar English dari A1 → C1 dengan target IELTS, memakai sumber gratis & open-source.
Situs statis (tanpa build) — cocok untuk GitHub Pages.

## Aktifkan GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)`.

## Edit kurikulum
Ubah `assets/data.js` (fase, checklist, link). Progress tersimpan di browser (localStorage).

## Struktur
- `index.html`, `assets/` — situs
- `journal/` — jurnal belajar (Markdown)
